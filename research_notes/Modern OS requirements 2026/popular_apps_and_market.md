# Popular apps, services and desktop OS market (EU, India, Gulf), state Oct 2026

Method note: ~17 searches/fetches. Many search hits are secondary aggregators; StatCounter pages were fetched directly but are rendered through a summarizer, and StatCounter figures varied between fetches and snippets (see Gaps). StatCounter measures page views on its tracker network, not installs, and has a large "Unknown" OS bucket since 2025-26.

## 1. Desktop OS market share (worldwide, India, EU, Gulf), Windows 11 vs 10, Linux growth drivers

### Takeaway
Windows holds roughly 75-80% of tracked desktop traffic in most focus regions. Windows 11 is now about 70% of Windows (Sept 2026). Linux sits around 4-5% worldwide and in the EU and Gulf. India is the Linux outlier at 10%+ in StatCounter, but that figure is volatile and partly an artifact of bot/unknown-traffic handling. Steam shows Linux at about 4-5%, driven by Steam Deck/SteamOS.

### Cited Findings
- Worldwide desktop, Sept 2026: Windows 76.36%, OS X 10.68%, macOS 6.1%, Linux 4.54%, ChromeOS 2.31% — [StatCounter](https://gs.statcounter.com/os-market-share/desktop/worldwide)
- A different StatCounter snapshot (June 2026) put Windows at 56.61% with "Unknown" at 21.45%, Linux 4.36%, ChromeOS 1.21%; Linux 4.39% in June called one of its strongest showings; Windows briefly dropped below 60% — [Linuxiac via search summary](https://linuxiac.com/windows-drops-under-60-in-global-desktop-os-share-for-the-first-time-in-years/) (page itself returned 404 on fetch; treat as unverified). Another snippet gave Aug 2026 as Windows 62.67% / Linux 8.88%, inconsistent with the above — [StatCounter](https://gs.statcounter.com/os-market-share/desktop/worldwide)
- Windows version, desktop worldwide, Sept 2026: Windows 11 71.44%, Windows 10 27.83%, Windows 7 0.55% — [StatCounter](https://gs.statcounter.com/windows-version-market-share/desktop/worldwide). A search snippet for Aug 2026 gave Win11 68.6% / Win10 30.14%, so Windows 10 is declining about 2 points per month — [StatCounter](https://gs.statcounter.com/windows-version-market-share)
- Windows 10 end of support was 14 Oct 2025; search-summary claims about about 1 billion devices left behind and TPM 2.0 incompatibility are secondary — [WebProNews](https://www.webpronews.com/windows-10-support-ends-users-migrate-to-linux-like-zorin-os-for-privacy/)
- India desktop, Sept 2026: Windows 82.31%, Linux 10.45%, macOS 4.14%, OS X 2.66%, ChromeOS 0.44% — [StatCounter India](https://gs.statcounter.com/os-market-share/desktop/india). Earlier snippet "Aug 2026": Windows 76.14%, Linux 12.56%, macOS 7.77% — same page. Another snippet notes May 2026 India Linux 5.33% with nearly half of traffic "Unknown"; and July 2024 India Linux 16.21% — [CommandLinux](https://commandlinux.com/statistics/desktop-os-market-share-by-country/) (secondary)
- Europe desktop, Sept 2026: Windows 77.28%, OS X 10.93%, macOS 5.57%, Linux 4.61%, ChromeOS 1.6% — [StatCounter Europe](https://gs.statcounter.com/os-market-share/desktop/europe)
- UAE desktop, Sept 2026: Windows 74.13%, macOS 10.47%, OS X 8.36% (Apple about 18.8%), Linux 5.55%, ChromeOS 1.49% — [StatCounter UAE](https://gs.statcounter.com/os-market-share/desktop/united-arab-emirates)
- Saudi Arabia desktop, Sept 2026: Windows 80.92%, OS X 10.24%, macOS 4.66% (Apple about 15%), Linux 4%, ChromeOS 0.17% — [StatCounter KSA](https://gs.statcounter.com/os-market-share/desktop/saudi-arabia)
- Steam survey: Linux 5.33% in March 2026 (first time above 5%, +3.10 points month over month, attributed largely to Steam Deck/handheld counting plus anomalies), 4.52% April, 3.99% May, 3.69% June, 4.01% July; Windows 92.33% in March, macOS 2.35% — [Videocardz](https://videocardz.com/newz/steam-on-linux-reaches-5-33-in-march-steam-survey-highest-share-on-record), [Wccftech](https://wccftech.com/steam-hardware-survey-march-2026/), [AgentUpdate](https://agentupdate.ai/news/steam-survey-july-2026-linux-reaches-four-percent)
- Steam April 2026 Linux distros: SteamOS Holo 23.05%, Arch 8.78%, CachyOS 8.37%, Linux Mint 22.3 7.47%, Bazzite 4.74% — [GamingOnLinux](https://www.gamingonlinux.com/2026/05/steam-survey-for-april-2026-shows-linux-still-trending-well/)
- Browsers (StatCounter, all platforms): India May 2026 Chrome 90.08%, Opera 3.16%, Safari 2.88%, Edge 1.05%, Firefox 0.68%; Europe Aug 2026 Chrome 62.66%, Safari 17.80%, Edge 6.66%, Firefox 4.61%; worldwide Aug 2026 Chrome 69.39%, Safari 15.83%, Edge 5.36%, Firefox 2.98% — [StatCounter via search](https://gs.statcounter.com/browser-market-share)
- Growth drivers cited (secondary, qualitative): Windows 10 EOL and Windows 11 hardware requirements, Steam Deck normalizing Linux, Proton, frustration with Windows updates/AI features — [DEV Community](https://dev.to/techpulselab/linux-desktop-in-2026-is-it-finally-ready-for-normal-people-42k0), [HowToGeek](https://www.howtogeek.com/reasons-2026-could-finally-be-the-year-of-desktop-linux/)

### Inferences
- For Nubo: the realistic mainstream-switcher pool is a Windows 10 (about 28% of Windows) base plus Windows 11-ineligible hardware; Linux is a single-digit niche everywhere except possibly India.
- Apple share is meaningfully higher in the Gulf (15-19%) than India, so Gulf users skew toward Apple ecosystem expectations (iCloud, iMessage, AirDrop-like flows).
- India's Linux number is probably inflated by developers, education, and traffic-classification noise; do not use 10%+ as a consumer-demand signal.
- StatCounter's volatility (Windows 56% to 76% across months) means treat all numbers as ranges.

### Gaps
- Kuwait, Qatar, Oman, Bahrain desktop OS shares not retrieved; individual EU countries (Germany, France etc.) not retrieved.
- Windows 11 vs 10 split for India/EU/Gulf not retrieved.
- Non-web trackers (IDC/Counterpoint India PC shipments, Gulf PC market, Canalys EU) not found; no data on how many PCs are Win11-ineligible beyond secondary claims.
- Steam Deck unit sales figure not retrieved (Valve does not publish).

## 2. Most used apps/websites by category in the focus regions

### Takeaway
Strong measured data found only for messaging (WhatsApp), browsers, and AI sites. Other categories (streaming, office, creative, banking/UPI, e-sign, PDF, cloud storage) were not quantified in this pass and remain gaps. A key Gulf-specific finding is VoIP restrictions that shape which call apps work.

### Cited Findings
- WhatsApp: 535.8M users in India (DataReportal 2025, largest country audience), used by 98% of internet users in India; about 3.3B MAU worldwide Q1 2026 per aggregators — [Hyperleap summary of DataReportal](https://hyperleap.ai/blog/whatsapp-statistics-india-2026), [Demandsage](https://www.demandsage.com/whatsapp-statistics/)
- WhatsApp penetration >75% in Qatar, Saudi Arabia, UAE etc. (Northwestern University in Qatar study, date not stated; UAE >80%); #1 messaging app in 63 of 100 countries incl. India, Germany, Spain, Saudi — [YCloud](https://www.ycloud.com/blog/whatsapp-statistics-for-businesses), [Timelines.ai](https://timelines.ai/whatsapp-stats)
- UAE VoIP: as of July 2026 WhatsApp/FaceTime voice and video calls remain blocked under TDRA policy; text messaging works; Zoom, Teams, Webex, Botim, GoChat, Voico, ToTok are on the approved list — [Simology](https://simology.io/blog/uae-voip-app-calling-what-works-what-doesnt-2026-traveller-guide), [Ritukant](https://ritukant.com/uae-whatsapp-calling/) (secondary, travel/blog sources)
- AI: Similarweb March 2026 global site ranks: ChatGPT #5, Gemini #15, Claude #49, Grok #96, DeepSeek #99, Perplexity #198 — [Similarweb on X](https://x.com/Similarweb/status/2042152237485445603). July 2026 AI-tools ranking: chatgpt.com, gemini.google.com, claude.ai, DeepSeek, grok — [Similarweb](https://www.similarweb.com/top-websites/ai-chatbots-and-tools/). India web-visit share cited as ChatGPT 9.6%, Gemini 6.1% (metric ambiguous) — [BusinessToday](https://www.businesstoday.in/amp/technology/artificial-intelligence/story/most-popular-ai-tools-in-2026-chatgpt-takes-the-top-spot-550382-2026-08-21)
- Flathub top downloads are Firefox, Google Chrome, Discord; Sober (Roblox client), Minecraft top games — [Flathub statistics via search](https://flathub.org/en/statistics)

### Inferences
- Nubo must have WhatsApp (via web/Flatpak wrapper), Chrome and Firefox, and Zoom/Teams working out of the box; in the Gulf, Botim/ToTok are mobile-first and have no desktop Linux story.
- Chrome is 60-90% of browsing; ship Chrome or Chromium-based option (Flathub Chrome is popular).
- AI assistants are web-first; install-as-web-app integration is enough.

### Gaps
- No quantified data retrieved for: Netflix/YouTube/Spotify/JioHotstar/Anghami/Shahid desktop usage, Microsoft 365 vs Google Workspace vs Zoho vs WPS share, Zoom/Teams/Meet by region, Canva/Figma/CapCut/Adobe, UPI/bank/government portals (DigiLocker, Aadhaar, UAE Pass, Absher/Nafath), e-signature, PDF tools, cloud storage shares. Sensor Tower/Comscore/GWI/Pew are paywalled and not reached.

## 3. Linux availability: native, web/PWA, Wine/Proton, impossible

### Takeaway
Daily tasks mostly work via browser and Flatpak; the hard blockers are Adobe CC, native Microsoft Office, hardware DRM streaming above 1080p, and kernel anti-cheat games. Banking/government app status was not found.

### Cited Findings
- Adobe Creative Cloud (Photoshop, Premiere, Illustrator) has no native Linux version; Photoshop installer reportedly runs under Wine but unsupported — [BGR](https://www.bgr.com/2070270/essential-windows-apps-not-on-linux/), [It's FOSS](https://itsfoss.com/news/photoshop-installer-runs-on-linux/)
- Microsoft Office desktop apps do not exist on Linux; Microsoft 365 web works; alternatives are LibreOffice, OnlyOffice, WPS, SoftMaker — [DEV Community](https://dev.to/techpulselab/linux-desktop-in-2026-is-it-finally-ready-for-normal-people-42k0)
- Linux browsers get Widevine L3 only, so Netflix and similar are capped near 1080p with no 4K/HDR — [LinuxCommunity.io thread](https://linuxcommunity.io/t/drm-the-final-barrier-to-linux-desktop-adoption/3760) (forum, lower reliability)
- Flathub carries Firefox, Chrome, Discord and many others; 3,678 desktop apps, 4.77B total downloads, 2,180 verified; 435M downloads in 2025 (+21% vs 360.4M in 2024) — [Linuxiac](https://linuxiac.com/flathub-sees-over-435-million-downloads-in-2025/), [Flathub](https://flathub.org/en/statistics)

### Inferences
- Not verified per-app in this pass: WhatsApp, Telegram, Signal, Spotify, Zoom, Teams, Canva, Figma, CapCut native vs web status; the writer should verify on Flathub before asserting.
- Android emulation (Waydroid) and bank apps: no source found.

### Gaps
- Per-app native/web/Wine matrix; banking/UPI/government (DigiLocker, UAE Pass, Absher) compatibility; Waydroid status; WPS/Zoho Linux availability.

## 4. Gaming

### Takeaway
Linux is about 4-5% of Steam, strongly driven by SteamOS/Steam Deck; Proton covers most of the catalog but kernel anti-cheat titles (Fortnite, Valorant, Battlefield 6) remain blocked.

### Cited Findings
- Steam Deck compat, Aug 2026: 8,939 Verified, 21,067 Playable, 6,848 Unsupported — [CommandLinux/ProtonDB-derived via search](https://commandlinux.com/statistics/proton-game-compatibility-on-linux/)
- Fortnite listed "Denied" on Linux; Battlefield 6 fails at Javelin anti-cheat on Proton (EA job listings mention possible Linux path); EAC/BattlEye support is per-developer opt-in — [Nerdzap](https://nerdzap.com/news/why-steam-deck-cant-play-fortnite-valorant-battlefield-6/), [SDHQ](https://steamdeckhq.com/news/ea-javelin-anti-cheat-support-linux-proton/), [CanIPlayOnLinux](https://caniplayonlinux.com/guides/anti-cheat-linux-2026/)
- Another source claims about 640 Steam Deck games broken due to anti-cheat — [Switchblade Gaming](https://www.switchbladegaming.com/handheld-gaming/anti-cheat-steam-deck-linux-2026/) (unverified)

### Inferences
- Gaming is a headline pull for a niche; Nubo should preinstall Steam via Flathub one-click path and Proton, but not promise competitive multiplayer.

### Gaps
- Gulf/India/EU-specific Steam Linux share; ProtonDB Platinum/Gold percentages; Steam Deck unit sales.

## 5. Why consumers choose/reject Linux; migration drivers (refurb PCs, schools, governments)

### Takeaway
Choice drivers: Windows 10 EOL, hardware ineligibility, privacy/AI-feature fatigue, Steam Deck exposure, cost. Rejection drivers: anti-cheat, Adobe/Office, DRM streaming, hardware quirks. Government moves in the EU are significant; India has long-standing state-level adoption. No rigorous consumer survey data (Pew/GWI) was found.

### Cited Findings
- France (8 Apr 2026): government reportedly ordered ministries to move 2.5M workstations from Windows to Linux; ministry transition plans due autumn 2026 — [Vucense](https://vucense.com/privacy-sovereignty/digital-independence/france-ditches-windows-linux-digital-sovereignty-2026_1/), [Yahoo](https://www.yahoo.com/news/articles/france-just-kicked-microsoft-off-161724952.html) (secondary; verify against official French sources, I could not)
- Schleswig-Holstein: reported 80% / 30,000 workplaces switched by end 2025, over EUR 15M/year licence savings, EUR 9M one-off cost (the claim that it used KDE neon is from a Medium aggregator and should be verified) — [Medium](https://medium.com/@techinfintrix/the-open-source-operating-system-taking-over-schools-hospitals-and-governments-a59dfb603b65)
- Denmark piloting Collabora (LibreOffice-based) in ministries, full implementation targeted 2026 — same search summary, [Tuta](https://tuta.com/blog/countries-ditching-microsoft-choosing-linux-digital-sovereignty)
- India: Kerala IT@School Linux in schools (claimed Rs 3,000 crore savings), Tamil Nadu advised BOSS Linux in 2014, Maya OS (DRDO, Ubuntu-based) for Defence internet PCs from 2023 — [NewsMinute](https://www.thenewsminute.com/kerala/how-switching-linux-based-free-os-saving-kerala-govt-schools-rs-3000-crore-101844), [Wikipedia](https://en.wikipedia.org/wiki/Maya_(operating_system)); FSFTN criticism of TN govt laptop OS choice 2026 — [FSFTN](https://blog.fsftn.org/tn-laptop-2026/)
- Zorin OS 18 (Oct 2025): 1M downloads in five weeks, 2M by 12 Jan 2026, 3.3M in 6 months with 78% from Windows PCs (Zorin's own figures as relayed) — [WebProNews](https://www.webpronews.com/zorin-os-18-hits-2-million-downloads-as-windows-users-migrate-to-linux/), [Wikipedia Zorin OS](https://en.wikipedia.org/wiki/Zorin_OS)

### Inferences
- Zorin's Windows-origin download share (about 3/4) is the best proxy for the target persona: Windows 10 users with ageing PCs.
- Downloads overstate installs.

### Gaps
- No consumer survey (Pew/GWI/etc.) on reasons for rejecting Linux; refurbished-PC channel data; EU Windows 10 ESU uptake; Indian state 2025-26 migrations; Gulf government stance.

## 6. What successful consumer Linux projects ship by default

### Takeaway
Limited verified data. Qualitative only; adoption numbers beyond Zorin and Steam survey shares not found.

### Cited Findings
- Pop!_OS 24.04 LTS (Dec 2025) first to ship COSMIC as default desktop — [Wikipedia COSMIC](https://en.wikipedia.org/wiki/COSMIC_desktop)
- Linux Mint 22.3 "Zena" released Jan 2026; seen on Steam at 7.47% of Linux users in April 2026 — [Linuxize](https://linuxize.com/post/best-linux-distros/), GamingOnLinux above
- Bazzite: Fedora-based immutable SteamOS-like distro, 4.74% of Linux Steam users (April 2026); SteamOS Holo 23.05% — [Wikipedia Bazzite](https://en.wikipedia.org/wiki/Bazzite_(operating_system)), GamingOnLinux above
- elementary OS: curated AppCenter, Ubuntu-LTS based — [SourceForge comparison](https://sourceforge.net/software/compare/Linux-Mint-vs-Pop-OS-vs-elementary-OS/)

### Inferences
- Common thread of winners: Windows-like familiarity (Zorin), immutable/zero-maintenance updates (Bazzite, SteamOS), codecs/drivers preinstalled, gaming ready.

### Gaps
- Default-app lists for each distro, Endless OS adoption, Mint/Pop download counts, DistroWatch ranks not retrieved.
