# Nubo Office brand pack

Our own files for the editor's branding, same layout the editor expects:
`branding.js`, `branding.css`, `images/`. Passed to the web interface build with
`--with-app-branding=office/brand`.

Do not copy files from Collabora's brand pack: they are marked all rights reserved.
Missing pieces (the icon variants, welcome slideshow, theme definitions) fall back to
the editor's unbranded defaults until we draw our own.

Credit line in About: "Built on Collabora Online and LibreOffice technology". Send the wording
to trademark@collaboraoffice.com before release.
