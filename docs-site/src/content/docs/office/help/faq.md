## The basics

### What is Nubo Office?

An office suite of four apps: Nubo Write for documents, Nubo Cells for spreadsheets, Nubo Present for presentations and Nubo Draw for drawings, plus a start screen.

### Is it free?

Early access builds are free to download and use.

### Which platforms does it run on?

Nubo OS and Linux first. Windows, macOS, Android, iPhone, iPad and the web are planned. See [Installing Nubo Office](/office/install/).

## Accounts, privacy and offline

### Do I need a Nubo account?

No, not for files on your computer. You need one only to open documents stored on a Nubo server.

### Does it work without internet?

Yes. After the first install, you can open, edit and save files on your computer offline. Documents on a server need a connection.

### Where do my files go?

Where you save them. Nubo Office does not move files anywhere on its own.

## Files

### Will my Word, Excel and PowerPoint files look right?

Most do. See [Files and formats](/office/features/formats/) for the formats and the limits.

### Which format should I save in?

`.docx`, `.xlsx` and `.pptx` if you share with Microsoft Office users. The OpenDocument formats (`.odt`, `.ods`, `.odp`) to keep every feature. PDF for a final copy.

### Can I open PDF files?

Yes, in Nubo Draw. See [Work with PDF files](/office/guides/work-with-pdf/).

## Features

### Can several people edit one document at the same time?

Not yet. It is planned for documents stored on a Nubo server. Comments and tracked changes work now.

### Is there a dark theme?

Yes. Choose **Dark Mode** in the View tab to switch between dark and light.

### Is there a spell checker?

Yes, **Auto Spell Check** in the Review tab, with a **Language** setting. See [Nubo Write](/office/features/write/).

### Can I use macros?

Macros written for other programs are not supported.

## Getting help

### Where do I report a problem?

**Help**, then **Report an issue** in any app, or support@nubo.email.
