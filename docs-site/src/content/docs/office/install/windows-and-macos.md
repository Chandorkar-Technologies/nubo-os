Neither version is available yet. This page says what to expect.
:::

## Windows 11

- An installer for Intel and AMD computers, and one for Arm computers.
- The same four apps, with the same look and the same files.
- Installers are signed, so Windows does not warn when you run them. Early builds may show a warning until signing is in place.

## macOS

- A disk image for Apple silicon, and one for Intel Macs.
- The same four apps. Drag Nubo Office to Applications.
- Early builds may show a warning from macOS until they are signed and notarised.

## Until then

You can open and edit the same files with Nubo Office on Linux and Nubo OS. Files move between platforms without conversion, because the formats are the same.
