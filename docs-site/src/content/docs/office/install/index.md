| Platform | How | Status |
|---|---|---|
| **Nubo OS** | Part of the desktop (the `nubo-office` package) | Launchers are in. The suite downloads on first use |
| **Linux** | Flatpak from the Nubo repository | Being finished |
| **Windows 11** | Installer | Planned |
| **macOS** | Disk image | Planned |
| **Android** | App | Planned |
| **iPhone and iPad** | App | Planned |
| **Web browser** | Signed in with Nubo Email | Planned |

The table on [nubosuite.tech/office](https://nubosuite.tech/office/) shows the current state with download links and checksums as soon as they exist.

## What you need

- **Linux:** a recent 64-bit distribution with Flatpak. An Intel or AMD computer first, then Arm.
- **Disk space:** a little over 1 GB for the suite and its runtime.
- **Internet** for the first install, and to receive updates. After that, the apps work offline.
