## Accessibility check

Every app has an accessibility check. In Nubo Write it is in two places: the **Review** tab and the **Help** tab. The check goes through the document and lists problems that make it hard for some people to read, such as pictures with no description.

Fix pictures by giving them a description: select the picture and use **Alt Text** in the Format tab. **Name** in the same tab gives an object a name.

## Screen reading

**Screen Reading** in the Help tab turns on support for screen readers. Choose it before you start with a screen reader.

## Keyboard

Everything in the ribbon can be reached with the keyboard. <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>F1</kbd> moves focus to the ribbon, and <kbd>Esc</kbd> brings it back to the document. The [shortcuts reference](/office/reference/keyboard-shortcuts/) lists the rest.

## Other helps

- **Zoom** in the View tab makes the page larger.
- **Invert Background** and **Dark Mode** change contrast.
- **Compact view** gives the page more room on a small screen.

:::note[What is not tested]
Support for screen readers has not been tested with specific products yet.
:::

## Verify

Open **Review**, then **Accessibility Check**. The check opens and reports on the document.
