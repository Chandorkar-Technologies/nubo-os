| Kind | Opens in | Formats |
|---|---|---|
| Documents | Nubo Write | `.docx`, `.doc`, `.odt`, `.rtf`, `.txt` |
| Spreadsheets | Nubo Cells | `.xlsx`, `.xls`, `.ods`, `.csv` |
| Presentations | Nubo Present | `.pptx`, `.ppt`, `.odp` |
| Drawings | Nubo Draw | `.odg`, `.vsd` |
| PDF | Nubo Draw | `.pdf`, to read and mark up, and to export |

`.docx`, `.xlsx` and `.pptx` are the formats of Microsoft Word, Excel and PowerPoint. `.doc`, `.xls` and `.ppt` are their older forms. The `.od*` formats are OpenDocument, an open standard that other free office suites read as well.

## Which format to choose

- **To share with people who use Microsoft Office:** save as `.docx`, `.xlsx` or `.pptx`.
- **To keep every feature of Nubo Office:** use the OpenDocument format.
- **To send a document that must not change:** export to PDF. See [Printing and export](/office/features/printing-and-export/).
- **To move data to another tool:** save a spreadsheet as `.csv`.

## How well files carry over

Most files look the same as in the program that made them. Complex page layouts, macros and some fonts can differ, as in any office suite other than the original. When a document looks wrong, check that its font is installed.

## Opening files

Open a file from Files, from the start screen, or with **File**, then **Open**. See [Open and save files](/office/use/open-and-save/).
