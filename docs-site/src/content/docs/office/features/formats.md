| Kind | Opens in | Formats |
|---|---|---|
| Documents | Nubo Write | `.docx`, `.doc`, `.odt`, `.rtf`, `.txt` |
| Spreadsheets | Nubo Cells | `.xlsx`, `.xls`, `.ods`, `.csv` |
| Presentations | Nubo Present | `.pptx`, `.ppt`, `.odp` |
| Drawings | Nubo Draw | `.odg`, `.vsd` |
| PDF | Nubo Draw | `.pdf` (open and mark up, and export) |

`.docx`, `.xlsx` and `.pptx` are the formats of Microsoft Word, Excel and PowerPoint. The `.od*` formats are OpenDocument, an open standard, which Nubo Office uses by default and which other free office suites also read.

## How well files carry over

Most files look the same as in the program that made them. Complex page layouts, macros and some fonts can differ, as in any office suite other than the original. If a document looks wrong, check that the font it uses is installed, and tell us about it.

## Exporting

You can save a copy in another format from the **File** tab. PDF is the common choice for sending a document that must not change. <!-- verify label: the File tab export entries -->
