Nubo Cells is for tables of numbers: budgets, lists, calculations and charts. It opens `.xlsx`, `.xls`, `.ods` and `.csv` files.

## The window

- **Tabs:** File, Home, Insert, Page Layout, Formulas, Data, Review, Format, View and Help.
- **Formula bar** under the tabs, with the cell name on the left and the contents of the cell on the right.
- **Grid** with column letters and row numbers.
- **Sheet tabs** along the bottom, with buttons to add a sheet and move between them.
- **Sidebar** for Style, Character, Number Format and Alignment.
- **Status bar** shows the selection and a sum or average of selected cells.

## What you can do

- **Formulas.** Type `=SUM(B2:B7)` in a cell to add a column, or build formulas from the **Formulas** tab.
- **Number formats.** Choose a category such as General, a number of decimal places, a percentage or a currency from the Number tools on Home or the sidebar.
- **Charts.** Select a range and add a chart from **Insert**. The chart sits on the sheet next to the data. <!-- verify label: Insert chart entry -->
- **Sort, filter and summarise.** The **Data** tab covers these.
- **Several sheets** in one file.
- **CSV.** Open a `.csv` file as a spreadsheet and save it back as CSV.
