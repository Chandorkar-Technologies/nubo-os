All three tasks start in the **File** menu.

## Print

1. Open **File**, then **Print**.
2. Choose your printer and options, and print.

You can also press <kbd>Ctrl</kbd>+<kbd>P</kbd>. The keyboard-shortcuts page lists "Print (Download as PDF)" next to "Print": in some setups Print produces a PDF to download, and then you print that file.

## Export to PDF

1. Open **File**, then **Export**.
2. Choose PDF.
3. Save the file.

A PDF looks the same on every computer, so it is the right choice for sending something that must not change.

## Save a copy in another format

1. Open **File**, then **Save As**.
2. Pick a name and a format, such as `.docx` or `.odt`.

The document you have open keeps its name. See [Files and formats](/office/features/formats/) for which format suits which purpose.

## Sign a document

**File**, then **Sign**, lets you sign the document.

## Verify

Open the exported file in a PDF viewer. It looks like your document.

## Troubleshooting

- **The printer is not listed.** Add it in the system Settings, then try again.
- **The PDF uses a different font.** The font in your document is not installed on this computer.
