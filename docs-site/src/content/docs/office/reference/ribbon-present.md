Tabs: **File**, **Home**, **Insert**, **Design**, **Transition**, **Slide Show**, **Review**, **Format**, **View**, **Help**.

## Home

Clipboard (Paste and related buttons), **New** and **Slide Layout**, Character (font and text style), Paragraph (lists, alignment, indents, spacing), Spacing & Color, **Shapes**, **Connectors**, Illustrations (image, table, chart and text box), **Search** and **Replace**.

## Insert

| Group | Buttons |
|---|---|
| Slides | New, Duplicate Slide, Delete Slide |
| Illustrations | Image, Media, Table, Chart, Shapes, Curve, Line |
| Links | Hyperlink, Comment |
| Field | Date and time fields |
| Text | Text Box, Vertical Text |
| Others | Header and Footer, Symbol |

## Design

| Group | Buttons |
|---|---|
| Master Slide Templates | A gallery of master slides |
| Themes | A gallery of colour themes, Add Theme |
| Slide | Slide Layout, Slide Size, Slide Properties, Header and Footer, Background Image |

## Transition

A gallery of transitions: **None**, **Wipe**, **Wheel**, **Uncover** and others. **Variant**, **Duration**, **On mouse click**, **After** (seconds), **Apply to All Slides**.

## Slide Show

| Group | Buttons |
|---|---|
| Start Slide Show | From Beginning, From Current Slide, Presenter View |
| Present | Present in Window |
| Set Up | Hide Slide |

## Review

Spelling, Language, Auto Spell Check, Hyphenation, Comment, Delete All Comments.

## Format

Character, Paragraph, Bullets and Numbering, Slide Properties, Line, Position and Size, Name, Alt Text.

## View

Full Screen, Reset zoom, Zoom Out, Zoom In, Compact view, Ruler, Status Bar, Collapse Tabs, Slide Views, Grid, Dark Mode, Invert Background, Sidebar.

## Help

Online Help, Keyboard shortcuts, Forum, Report an issue, Latest Updates, Screen Reading, About.
