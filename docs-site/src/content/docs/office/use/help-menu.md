Every app has a **Help** tab. It holds:

| Entry | What it does |
|---|---|
| **Online Help** | Opens the built-in help |
| **Keyboard shortcuts** | Lists the shortcuts for the app you are in |
| **Forum** | Opens the Nubo documentation |
| **Report an issue** | Opens the issue tracker, where you can describe a problem |
| **Latest Updates** | Shows the welcome slides again |
| **Screen Reading** | Turns on support for screen readers |
| **Accessibility Check** | Checks the document for accessibility problems |
| **About** | Shows the product name, version and licence information |

## Report a problem

Choose **Report an issue**, or email support@nubo.email. Include the app, what you did and what you expected. If the problem is in one file, say what kind of file it is.

## Verify

Open **Help**, then **About**. The window names Nubo Office and the version.
