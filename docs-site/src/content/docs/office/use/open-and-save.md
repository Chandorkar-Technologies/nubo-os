## Open a file

- **From Files:** double-click a document, or right-click and choose **Open With**.
- **From the app:** use the **File** tab, then **Open**. <!-- verify label: File tab entries -->
- **From the start screen:** pick a document under **Recent**, or choose **Open** on the left.
- **From a Nubo server:** the app shows the server's own page for you to pick a document. See [Accounts and files](/office/account/).

## Save

Press <kbd>Ctrl</kbd>+<kbd>S</kbd> to save. A document keeps the format it was opened in. To save a copy in another format, such as PDF, use the **File** tab. <!-- verify label: Save As and export entries -->

## Editing and viewing modes

A file opened from outside can start in **Viewing** mode, which shows the page without the ribbon. Use the mode button at the top right and choose **Editing Mode** to edit.

## Verify

Edit a document, save it, close the app and open the file again. Your change is there.

## Troubleshooting

- **The ribbon is missing.** The file opened in Viewing mode. Switch to **Editing Mode**.
- **A character shows as a box.** The font in the file is not installed. Install the font, or choose another one.
