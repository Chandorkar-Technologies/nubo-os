**Applies to:** Desktop

## Before you begin

You need Nubo OS, or Linux with Nubo Office installed. On the first start, the computer must be online, because the suite is downloaded then. See [Linux and Nubo OS](/office/install/linux/).

## From the app grid

1. Open the app grid and find **Nubo Office**, **Nubo Write**, **Nubo Cells**, **Nubo Present** or **Nubo Draw**.
2. Open one. On the first start, a small window shows the download. Wait for it to finish.
3. The app opens. **Nubo Office** opens the start screen with templates.

## From a file

In Files, right-click a document and choose **Open With**. Documents list Nubo Write, spreadsheets Nubo Cells, and presentations Nubo Present.

## From a terminal

```bash
nubo-office write       # Nubo Write
nubo-office cells       # Nubo Cells
nubo-office present     # Nubo Present
nubo-office draw        # Nubo Draw
nubo-office office      # the start screen
nubo-office write ~/Documents/letter.docx
```

## Verify

The window title carries the app's name, and the ribbon has its colour: blue for Write, green for Cells, orange for Present, violet for Draw.

## Troubleshooting

- **Nothing happens on the first click, or a download error appears.** The computer is offline, or the download service cannot be reached. Connect and open the app again.
- **The window shows another product name.** You are running the version downloaded on first use. The Nubo build takes its place when it is published.
- **"Open With" does not list the Nubo apps.** Log out and in so the desktop reads the new launchers.
