Nubo Office has one window design for all four apps. Each app has its own accent colour, the same one as its icon, so you can tell them apart at a glance.

| App | For | Accent | Opens |
|---|---|---|---|
| **Nubo Write** | Letters, reports, anything with paragraphs. Styles, tables, comments and tracked changes. | Blue | `.docx` `.doc` `.odt` `.rtf` `.txt` |
| **Nubo Cells** | Tables, numbers, formulas and charts. | Green | `.xlsx` `.xls` `.ods` `.csv` |
| **Nubo Present** | Slides, with notes, transitions and a presenter view. | Orange | `.pptx` `.ppt` `.odp` |
| **Nubo Draw** | Diagrams, flyers and simple drawings. Also opens PDF. | Violet | `.odg` `.vsd` `.pdf` |
| **Nubo Office** | The start screen: templates, recent documents, and the way into the other four. | Blue | any of the above |

The editor underneath is the same for all of them. A document looks the same on every platform that runs Nubo Office.

## What you see

- A start screen with templates (Blank Document, CV, business letters and others) and a list of recent documents.
- A ribbon with the tabs File, Home, Insert and so on, which differ per app, and a sidebar for styles, character and paragraph settings.
- A dark window in all tests so far. The light theme has not been checked.
- The Help menu with Online Help, Keyboard shortcuts, Forum, Report an issue, Latest Updates and About. Forum opens these docs, and Report an issue opens the Nubo OS issue tracker on GitHub.
- The About window names the product, the version, and the technology it is built on.

## Tested so far

The four apps open and show a blank document with their own colours. Opening and saving real files, the light theme, and printing have not been tested yet. This page changes as they are.
