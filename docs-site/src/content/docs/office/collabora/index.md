Nubo Office is built from the open-source code of Collabora Online and Collabora Office, which is based on LibreOffice. We build it ourselves from source, with our own names, logos, colours and welcome slides. This section holds everything about that work.

- [Licence and trademark rules](/office/collabora/licence-and-trademark/): what the licence lets us do, what we must remove and keep.
- [Source and build](/office/collabora/source-and-build/): the code, the build steps for the engine and the desktop app, and what each platform needs.
- [The rebrand script](/office/collabora/rebrand-script/): what `office/rebrand.py` changes in a Collabora checkout and how to run it.
- [The brand pack and icons](/office/collabora/brand-pack/): our logos, colours, icon family, welcome slides and how they are made.
- [Platforms and build requirements](/office/collabora/platforms/): Linux, web, Windows, macOS, Android and iOS, in the order we plan them.
- [Pipeline for Nubo Office](/office/collabora/pipeline/): the Flatpak build in Drone and the Nubo Flatpak repository.
- [The web editor](/office/collabora/web-server/): replacing the document editor at `office.nubo.email`.
- [First build results](/office/collabora/first-build/): what ran, what we checked and what is left.

:::note
Nubo Office is not made or endorsed by Collabora or by The Document Foundation. "Collabora" and "LibreOffice" are trademarks of their owners. We name them only to say what the suite is built on.
:::
