**Applies to:** Nubo Write

The **Form** tab adds fields that people fill in.

## Before you begin

A document is open, with the labels for your fields typed in.

## The fields

| Button | Adds |
|---|---|
| **Rich Text** | A box for text that can be formatted |
| **Checkbox** | A box to tick |
| **Dropdown** | A list to choose from |
| **Picture** | A place for an image |
| **Date** | A date picker |
| **Properties** | The settings of the selected field |

## Steps

1. Click where the field should go, next to its label.
2. Open the **Form** tab and choose the field.
3. Select the field and choose **Properties** to set its name and, for a dropdown, its list.
4. Repeat for the other fields.

## Verify

Click each field. The checkbox ticks, the dropdown opens and the date picker shows a calendar.

## Troubleshooting

- **A field cannot be edited.** Make sure the document is in **Editing** mode, and not Viewing.
