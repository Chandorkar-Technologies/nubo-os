The reference pages hold exact values and no narrative. Use them to look something up. For explanations and step-by-step guides, see the sections for the [desktop](/desktop/), the [server](/server/) and [updates](/updates/).

## Pages in this section

- [Commands](/reference/commands/): every command Nubo OS adds, with its synopsis, options, examples and exit behavior.
- [Packages](/reference/packages/): every `nubo-*` package with its description, architecture, dependencies, conflicts and the editions that install it.
- [Files and paths](/reference/files-and-paths/): where each Nubo package puts its files, and which files you may change.
- [Configuration keys](/reference/configuration-keys/): the desktop defaults (gsettings), extension keys and the settings files in your home folder.
- [Network ports and endpoints](/reference/network-ports-and-endpoints/): the addresses Nubo OS contacts and the ports the server opens.
- [Editions comparison](/reference/editions-comparison/): Desktop, Server, Virtualization, Containers and Edge side by side.
- [Release notes](/reference/release-notes/): what changed in the 0.8.0 beta builds and the earlier development releases.
- [Known issues](/reference/known-issues/): what is untested, unfinished or planned.
- [Licences and credits](/reference/licences-and-credits/): the licences of Nubo OS, the brand files and the components Nubo OS builds on.

## About these pages

- Values are read from the source repository. Where a value could not be confirmed, the page says so.
- A section marked **Planned** describes something that is not built yet.
- Commands in the reference are for Nubo OS 1 "Flow", built on Ubuntu 26.04 LTS. For commands that belong to Ubuntu, see the Ubuntu documentation: [Server](https://ubuntu.com/server/docs), [Desktop](https://ubuntu.com/desktop/docs).
