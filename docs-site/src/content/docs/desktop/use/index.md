**Applies to:** Desktop

This section explains how the Nubo OS desktop works day to day. The desktop is GNOME 50 on Ubuntu 26.04 LTS, with Nubo's own look, a few extensions and some defaults changed. Anything that is plain GNOME behaves the way GNOME's own help describes it. These pages cover what is different or specific to Nubo OS.

![The Nubo desktop with the top bar, a clock widget and the dock](../../../../assets/screens/desktop.jpg)
