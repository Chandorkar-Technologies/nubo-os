**Applies to:** Desktop

Nubo Search is the launcher for Nubo OS. You press one shortcut, type, and open an app or a result. It is built on Vicinae, an open source launcher, with Nubo's settings on top. This page shows how to use it, how it is configured and how to fix common problems.

## Before you begin

Nubo Search is installed with the desktop (the `nubo-search` package) and runs from login. You do not need to start it. It is built for amd64 and arm64.

## Open and close it

1. Press <kbd>Super</kbd>+<kbd>Space</kbd>.
2. A search window opens. Type to search.
3. Press <kbd>Esc</kbd> or <kbd>Super</kbd>+<kbd>Space</kbd> again to close it.

The shortcut runs `nubo-search toggle`. You can also run that command from a terminal or a launcher. There is also an app entry named Nubo Search, described as "Search apps, files and more".

:::note
In stock GNOME, <kbd>Super</kbd>+<kbd>Space</kbd> switches keyboard layouts. Nubo moves layout switching to <kbd>Alt</kbd>+<kbd>Shift</kbd> to free the shortcut. See [Keyboard shortcuts](/desktop/use/keyboard-shortcuts/).
:::

## What it searches

The package describes Nubo Search as a way to search apps, files and more. Apps are the main use: type the first letters of an app and press <kbd>Enter</kbd>. Vicinae has more features than the ones Nubo documents here, such as extensions; those belong to Vicinae and are not tested or supported as part of Nubo OS. See the Vicinae project for them. <!-- verify label: list of built-in search sources (files, clipboard history, emoji, calculator) is not confirmed in the Nubo repo -->

This is different from the search field in the Activities overview, which is GNOME's own.

## How it runs

- The background service starts at login (`nubo-search server`, from an autostart entry for the GNOME session). It keeps the window quick to open.
- `nubo-search toggle` shows or hides the window. Other arguments are passed to Vicinae.
- The launcher's libraries are inside the package at `/usr/lib/nubo/search`. The `nubo-search` script puts them on the library path for its own process only, so they do not affect other programs.

## Configuration

Nubo's defaults are in `/usr/share/nubo/search/nubo.json`. Do not edit this file; a package update replaces it. It sets:

| Setting | Nubo value |
|---|---|
| `telemetry.system_info` | `false` (no system information is sent) |
| `tray.enabled` | `false` (no tray icon) |
| `theme.light` | name `libadwaita-light`, icon theme `auto` |
| `theme.dark` | name `libadwaita-dark`, icon theme `auto` |

Your own settings live in `~/.config/vicinae/settings.json` (or in `$XDG_CONFIG_HOME/vicinae/` if you set that variable). On first run, Nubo writes this file so that it imports the Nubo defaults:

```json title="~/.config/vicinae/settings.json"
{
  "$schema": "https://vicinae.com/schemas/config.json",
  "imports": ["/usr/share/nubo/search/nubo.json"]
}
```

Add your own settings below the `imports` line. They are yours, and Nubo does not change them afterward. The theme follows light and dark mode (see [Light and dark appearance](/desktop/use/light-and-dark/)).

## First run

The first time you run Nubo Search:

1. The script checks for `~/.config/vicinae/settings.json`.
2. If the file does not exist, or does not contain an `imports` entry, it creates the folder and writes the file shown above.
3. It starts Vicinae.

If you have a Vicinae settings file with an `imports` entry already, it is not touched.

## Verify

1. Press <kbd>Super</kbd>+<kbd>Space</kbd>. The search window opens.
2. Type "Settings". The Settings app appears in the results.
3. Check the file: `cat ~/.config/vicinae/settings.json`. It contains the `imports` line.

## Troubleshooting

**Nothing happens when I press the shortcut.**
Cause 1: you had custom shortcuts before Nubo's login script ran, so it did not add this one. Fix: open Settings, go to the keyboard shortcuts and add a custom shortcut named Nubo Search with the command `/usr/bin/nubo-search toggle` and the keys <kbd>Super</kbd>+<kbd>Space</kbd>. <!-- verify label -->
Cause 2: the shortcut is taken by the input source switcher. Fix: check [Keyboard and input](/desktop/settings/keyboard-and-input/).

**The window opens slowly the first time.**
Cause: the service was not running yet. Fix: log out and in. Run `pgrep -a vicinae` to see if it is running.

**The tray icon or settings I changed are not applied.**
Cause: your `settings.json` loads after the Nubo defaults, so check for a typing error in your file.

**A command not found error appears for `nubo-search`.**
Cause: the package is not installed. Fix: `sudo apt install nubo-search`.
