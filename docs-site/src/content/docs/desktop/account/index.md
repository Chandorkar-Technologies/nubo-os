**Applies to:** Desktop

Nubo OS works without any account. You can install it, create a local user and use every app on the desktop with no sign-in. A Nubo account is optional. It gives you an email address at `nubo.email`, a calendar, an address book and a file area on one server (`mail.nubo.email`), and it can also be used to sign in to the computer.

This section covers the account itself and the apps that connect to it. Some parts are early access or preview, and each page says so. Parts that are not built yet are marked **Planned**.
