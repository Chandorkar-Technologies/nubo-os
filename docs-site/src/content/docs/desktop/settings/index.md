**Applies to:** Desktop

Nubo OS uses GNOME's Settings app. This section covers the settings people change most, with the parts that are specific to Nubo OS. For anything that behaves exactly as on Ubuntu 26.04 LTS, the pages are short and link to Ubuntu's documentation at https://ubuntu.com/desktop/docs.

## Open Settings

Use any of these:

1. Click the gear icon in the dock. Settings is pinned there by default.
2. Open [quick settings](/desktop/use/quick-settings/) and click the gear button in the top row.
3. Press <kbd>Super</kbd>+<kbd>Space</kbd> and type "Settings" ([Nubo Search](/desktop/use/nubo-search/)).

## What Nubo changes

Nubo OS sets defaults through a GNOME settings override (`90_nubo.gschema.override`) and a login helper. These touch the theme, wallpaper, dock, widgets, sound theme, Files view and the layout switching shortcut. Everything else in Settings is stock.

Some labels in Settings differ between GNOME versions. These pages describe the action and note where a label is not confirmed.
